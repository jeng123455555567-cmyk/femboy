NUTT Dashboard v6 - Companion + Femboy Photo Manager

เปิดใช้งาน:
1. แตก ZIP
2. ดับเบิลคลิก start-server.bat
3. เปิด http://localhost:8000/
4. ใช้ Chrome หรือ Edge รุ่นใหม่

แก้ไขรอบนี้:
- แก้ปัญหาแชทไม่ส่ง/ไม่ตอบกลับจากลำดับการโหลด JavaScript
- ปุ่ม quick chat ใช้งานจริง
- ตอบกลับตามบริบท: อ้อน, เหนื่อย, กำลังใจ, โค้ด/บั๊ก, เรียน และข้อความทั่วไป
- ข้อความ Companion ไม่ซ้ำตามจำนวนวันที่ตั้งไว้ (ค่าเริ่มต้น 30 วัน)
- สุ่มรูปในแชท และไม่สุ่มรูปเดิมซ้ำตามจำนวนวันที่ตั้งไว้
- ตั้งเวลา Companion และส่ง notification เมื่อเบราว์เซอร์อนุญาต
- ตั้งค่า > คลังรูป femboy:
  * ดูรูปทั้งหมด
  * เลือกโฟลเดอร์ femboy จากเครื่องแบบ read/write
  * เพิ่มรูปหลายรูปพร้อมกัน
  * ตั้งชื่อ image1, image2, ... อัตโนมัติ
  * ลบรูป
  * จัดเลขใหม่ให้ต่อเนื่อง
- assets/femboy ใน ZIP ยังเก็บรูปเดิมทั้งหมดไว้
- ระบบเดิม BMI / Workout / Calendar / Portfolio / Backup / Restore / Google Drive ยังอยู่

หมายเหตุเรื่องสิทธิ์ไฟล์:
Browser ไม่อนุญาตให้เว็บเขียนไฟล์ลง assets/femboy ของโปรเจกต์โดยอัตโนมัติ เพื่อความปลอดภัย จึงต้องกด "เลือกโฟลเดอร์ femboy" และเลือกโฟลเดอร์เดียวกันจากเครื่อง 1 ครั้ง หลังจากนั้นการเพิ่ม/ลบ/จัดเลขจะเขียนไฟล์จริงในโฟลเดอร์นั้นได้

แนะนำ Chrome/Edge และต้องเปิดผ่าน localhost จาก start-server.bat เพื่อให้ File System Access API ทำงานได้เต็มที่
